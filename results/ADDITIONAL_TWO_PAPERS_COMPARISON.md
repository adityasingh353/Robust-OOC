# ADDITIONAL TWO PAPERS COMPARISON

## Target Paper 3: A Textual-Visual-Entailment-based Unsupervised Algorithm for Cheapfake Detection

- **Paper**: A Textual-Visual-Entailment-based Unsupervised Algorithm for Cheapfake Detection (ACM Multimedia 2022)
- **Task**: Cheapfake Detection (OOC/NOOC)
- **Repository**: https://github.com/pwnyniche/acmmmcheapfake2022
- **Code**: Present (`acmmm.py`). Includes the original COSMOS codebase and OFA integrations.
- **Checkpoint**: Uses public HuggingFace models (`microsoft/deberta-xlarge-mnli`) and OFA/Detectron2 weights. No custom trained weights required since it is unsupervised.
- **Raw-image preprocessing**: Supported on the fly via the embedded COSMOS codebase (using Detectron2 Mask R-CNN).
- **900-sample compatibility**: Yes, can be evaluated on our 900 samples by formatting them into `test_data.json` and placing raw images in the `public_test_mmsys` folder.
- **GPU requirement**: GPU with minimum 10GB memory.
- **External dependencies**: Docker recommended; heavily relies on older PyTorch (1.9.0), CUDA 11.1, Detectron2, and OFA.
- **Reproducibility status**: Feasible (Exact Reproduction). The use of an unsupervised algorithm and public checkpoints makes this highly reproducible if the Docker container runs successfully.
- **Engineering risk**: Medium. Setting up the exact Detectron2/COSMOS visual extraction pipeline can be brittle, but the provided Dockerfile heavily mitigates this risk.
- **Recommended next action**: **KEEP**

## Target Paper 4: A Combination of Visual-Semantic Reasoning and Text Entailment-based Boosting Algorithm for Cheapfake Detection

- **Paper**: A Combination of Visual-Semantic Reasoning and Text Entailment-based Boosting Algorithm for Cheapfake Detection (ACM Multimedia 2022)
- **Task**: Cheapfake Detection (OOC/NOOC)
- **Repository**: https://github.com/latuanvinh1998/Cheapfakes_detection_acmmm
- **Code**: Present (`ACMMM/acmmm_evaluate_task_1.py`), but highly fragmented across submodules (`bottom-up-attention`, `VSRN`).
- **Checkpoint**: MISSING. The inference script hardcodes a requirement for a custom trained network (`Model/model_acmmm_best_84,8%.pth`) which is not in the repository.
- **Raw-image preprocessing**: NOT SUPPORTED by the inference script. Expects pre-extracted `.npy` arrays generated by Pete Anderson's `bottom-up-attention` (Caffe).
- **900-sample compatibility**: Highly problematic. To process our 900 raw images, we must compile and run the legacy Caffe `bottom-up-attention` repository, which is notorious for breaking on modern hardware.
- **GPU requirement**: GPU required for Caffe/bottom-up-attention and PyTorch inference.
- **External dependencies**: Caffe, OpenCV (legacy versions), specific CUDA 8/9 environments for bottom-up-attention.
- **Reproducibility status**: Blocked (Missing Checkpoints).
- **Engineering risk**: Very High / Blocked. The missing boosting checkpoints and the reliance on ancient Caffe code make this paper essentially unreproducible without massive engineering effort and training from scratch on the original dataset (which violates our evaluation-only mandate).
- **Recommended next action**: **DROP** (Reason: Missing custom checkpoints and reliance on legacy Caffe extraction pipelines that cannot process raw images natively).

---

## FINAL DECISION & RECOMMENDATION

**Paper 3 (Unsupervised Algorithm): KEEP** — Proceed to 10-sample pilot.
**Paper 4 (Boosting Algorithm): DROP** — Missing crucial checkpoints and uses an obsolete, highly brittle Caffe visual extraction pipeline.

**Recommendation**: 
We should implement **Target Paper 3** first. Because it is an entirely unsupervised method relying on publicly accessible foundational models (DeBERTa, OFA, Detectron2), the reproducibility/setup risk is significantly lower. We do not have to worry about missing custom weights, and the repository natively supports processing raw images via its embedded COSMOS module, ensuring seamless compatibility with our 900-sample evaluation set.
