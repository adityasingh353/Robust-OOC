# Result Library

This folder contains all the official metrics, summaries, and key findings for the RobustOOC project. It is structured to make writing the M.Tech dissertation as easy as possible.

## Contents
- **`baseline_A_summary.md`**: Evaluation results for the first baseline (NLI + CLIP).

- **`reproducibility_audits_summary.md`**: Documentation of why certain external state-of-the-art models (like Unified Network and CSGM) could not be evaluated due to missing preprocessing artifacts.
